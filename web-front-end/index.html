前端 ⇄ 后端 交互示例

后端：原生 Node.js (server.js)  |  前端：fetch API

1. GET 请求（请求/响应模式）

点击按钮 → 浏览器发送 GET /api/time → 后端返回 JSON。

（尚未请求）

2. POST / DELETE（JSON 增删）

新增：发送 POST /api/todos，请求体为 JSON； 删除：发送 DELETE /api/todos/:id。

    3. SSE 服务端推送（Server-Sent Events）

    建立连接后，后端每 2 秒主动推送一条消息（无需前端反复请求）。

    （尚未连接）
